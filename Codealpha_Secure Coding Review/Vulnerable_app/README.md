# Vulnerable Flask Application

## Overview

This directory contains the intentionally vulnerable version of the Python Flask web application used during the Secure Coding Review project.

The application includes several common web application vulnerabilities that were intentionally retained for educational purposes and security analysis.

## Identified Vulnerabilities

- Reflected Cross-Site Scripting (XSS)
- SQL Injection
- Plaintext Password Storage
- Password Information Disclosure
- Flask Debug Mode Enabled

## Purpose

This version of the application was used to:

- Perform manual source-code review
- Conduct manual security testing
- Execute static analysis using Bandit
- Demonstrate common web application vulnerabilities

## Warning

This application is intentionally insecure and is provided solely for educational purposes.

**Do NOT deploy this application in a production environment.**
